# Hermes Agent fork playground

This fork is a personal playground for Hermes Agent patches, experiments, and small fixes before they are proposed upstream.

Upstream project: https://github.com/NousResearch/hermes-agent

For native Windows installation, use the upstream [PowerShell installer (`scripts/install.ps1`)](https://github.com/NousResearch/hermes-agent/blob/main/scripts/install.ps1).

## What lives here

- focused bug-fix branches
- local experiments for messaging, TTS, and Hermes gateway behavior
- pull-request staging branches intended for upstream review

This repository is not a separate distribution of Hermes Agent. For installation, documentation, and the canonical README, use the upstream project.

## AI-assisted development

Some patches in this fork may be developed with AI agent assistance under human direction and review. Upstream pull requests will disclose that where relevant.
